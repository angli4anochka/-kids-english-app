## 5. Риски и замечания

### Критические риски
1. **Google Fonts**: IP и User-Agent уходят в Google (США) при загрузке шрифтов. Решение: self-host шрифты или использовать системные.
2. **Google OAuth**: при входе через Google данные передаются Google. Решение: добавить уведомление в форму входа или отключить OAuth.
3. **Лидерборд** `/scoreboard`: публично показывает имена учеников. Требуется отдельное согласие `public_profile`.
4. **Токены авторизации**: используется Base64 (не JWT) — токены подделываемы. Безопасность риск.
5. **CORS**: открыт для всех Origins. Все API-эндпоинты публичны без проверки авторизации.

### Средние риски
6. **Пароль БД**: `postgres:postgres` в production — сменить.
7. **Plaintext пароли учеников**: backend возвращает `plain_password` при создании студента — не хранить в открытом виде.

### Низкие риски  
8. Нет robots.txt — страницы могут индексироваться.
9. Нет rate limiting на формы авторизации.
